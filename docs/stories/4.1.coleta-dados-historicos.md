# Story 4.1: Coleta e Processamento de Dados Históricos

## Status

Draft

## Story

**As a** pipeline ML,
**I want** coletar e armazenar dados históricos OHLCV da Binance com pelo menos 2 anos de histórico,
**so that** o modelo ML tenha dados suficientes para treinamento e validação confiáveis.

## Acceptance Criteria

1. Script de download de dados históricos OHLCV via CCXT para pares configurados (BTC/USDT, ETH/USDT)
2. Dados baixados para mínimo 2 anos em timeframes de 5m, 1h e 1d
3. Dados armazenados em formato Parquet (comprimido) na pasta `backend/ml/data/`
4. Script de validação de qualidade dos dados: detecta e remove candles duplicados, nulos e gaps > 3 candles consecutivos
5. Pipeline de dados incrementais: script de atualização diária baixa apenas candles novos desde o último download
6. Testes unitários para funções de validação e limpeza de dados

  - [ ] Método `download_all(symbols, timeframes, years_back=2)`:
    - Chamar `download_historical()` para cada combinação symbol × timeframe
    - Salvar cada resultado como Parquet comprimido: `backend/ml/data/{symbol}/{timeframe}.parquet`
    - Exibir progresso via `tqdm`
- [ ] Criar script de download inicial (AC: 1, 2, 3)
  - [ ] `scripts/download_data.sh`: wrapper shell que chama `python -m ml.data_collector --all --years 2`
  - [ ] Ou `backend/ml/pipeline.py`: método `initialize_data()`
- [ ] Implementar validação de qualidade (AC: 4)
  - [ ] `backend/ml/data_collector.py`: método `validate_and_clean(df)`:
    - Remover duplicatas por timestamp: `df.drop_duplicates(subset="timestamp")`
    - Remover candles com campos nulos: `df.dropna()`
    - Detectar gaps: calcular diferença entre timestamps consecutivos; identificar gaps > 3× timeframe

## Dev Notes

**Binance OHLCV via CCXT — paginação:**
```python
import ccxt

exchange = ccxt.binance()
all_ohlcv = []
since = exchange.parse8601("2024-01-01T00:00:00Z")

while True:
    batch = exchange.fetch_ohlcv("BTC/USDT", "1h", since=since, limit=1000)
    if not batch:
        break
    all_ohlcv.extend(batch)
    since = batch[-1][0] + 1  # próximo milissegundo
    if batch[-1][0] >= exchange.milliseconds():
        break

df = pd.DataFrame(all_ohlcv, columns=["timestamp", "open", "high", "low", "close", "volume"])
df["timestamp"] = pd.to_datetime(df["timestamp"], unit="ms", utc=True)
```

**Limites de dados históricos da Binance:**
- Spot OHLCV: até 3 anos disponível
- Limite de requisição: 1000 candles por chamada
- Rate limit: ~1200 requisições/minuto (tier free)

```python
import pandas as pd
import pytest
from ml.data_collector import DataCollector

@pytest.fixture
def sample_df():
    # Criar DataFrame de 100 candles sintéticos, 1 hora cada
    dates = pd.date_range("2026-01-01", periods=100, freq="1h", tz="UTC")
    return pd.DataFrame({
        "timestamp": dates,
        "open": 28000.0, "high": 28500.0, "low": 27800.0, "close": 28200.0, "volume": 1000.0
    })

def test_remove_duplicates(sample_df):
    duped = pd.concat([sample_df, sample_df.iloc[:5]])  # 5 duplicatas
    collector = DataCollector()
    clean = collector.validate_and_clean(duped)
    assert len(clean) == len(sample_df)
```
