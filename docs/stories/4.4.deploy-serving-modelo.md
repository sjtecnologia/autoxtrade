# Story 4.4: Deploy e Serving do Modelo em Produção

## Status

Draft

## Story

**As a** engine de trading,
**I want** consultar o modelo ML em tempo real para obter sinal de direção (LONG/SHORT/NEUTRO),
**so that** as decisões de abertura de posição sejam baseadas em predições ML atualizadas.

## Acceptance Criteria

1. Endpoint `POST /api/v1/ml/predict` recebe símbolo e retorna predição (LONG/SHORT/NEUTRO) com nível de confiança
2. Predições com confiança < 0.60 são automaticamente classificadas como NEUTRO (sinal insuficiente)
3. Apenas um modelo por símbolo pode estar ativo (`status="active"`) em `ml_models` ao mesmo tempo
4. Endpoint `POST /api/v1/ml/rollback` permite retornar ao modelo anterior em caso de degradação
5. Modelo é carregado em memória no startup do servidor (não relido do disco a cada predição)
6. Retrain semanal automático (Celery Beat) — novo modelo só ativa se aprovado E após comando manual ou aprovação automática via dashboard
7. Testes de integração para endpoints de predict e rollback

## Tasks / Subtasks

- [ ] Implementar ModelPredictor (AC: 1, 2, 5)
  - [ ] `backend/ml/predictor.py`: classe `ModelPredictor`
  - [ ] `__init__()`: dicionário `_models: dict[str, LoadedModel]` (cache em memória por símbolo)
  - [ ] Método `load_model(symbol)`:
    - Buscar no banco `ml_models` onde `symbol=symbol AND status="active"`
    - Carregar arquivo pkl: `joblib.load(model_path)`
    - Carregar scaler: `joblib.load(scaler_path)`
    - Armazenar em `_models[symbol]`
  - [ ] Método `predict(symbol, latest_ohlcv_df)`:
    - Verificar se modelo carregado: se não, chamar `load_model(symbol)`
    - Calcular features: `FeatureEngineer().calculate_features(latest_ohlcv_df)`
    - Aplicar scaler: `scaler.transform(features[-1:])`  (apenas último candle)
    - Obter probabilidades: `model.predict_proba(X_latest)` → `[P(LONG), P(NEUTRO), P(SHORT)]`
    - Confiança = probabilidade da classe mais votada
    - Se confiança < 0.60: retornar `NEUTRO`
    - Retornar `PredictionResult(signal, confidence, model_version)`
  - [ ] Método `reload(symbol)`:
    - Re-carregar modelo do banco (usado após ativação de novo modelo)
    - Atualizar cache `_models[symbol]`

## Dev Notes

**Formato de predição probabilística:**
```python
# RandomForestClassifier retorna probabilidades por classe
proba = model.predict_proba(X)  # shape: (1, 3) → [P(LONG), P(NEUTRO), P(SHORT)]
classes = model.classes_        # ["LONG", "NEUTRO", "SHORT"]

confidence = max(proba[0])
predicted_class = classes[np.argmax(proba[0])]

if confidence < 0.60:
    predicted_class = "NEUTRO"
```

**Rollback de modelo:**
```python
# 1. Inativar modelo atual
current_model = db.query(MLModel).filter_by(symbol=symbol, status="active").first()
current_model.status = "retired"

# 2. Ativar o mais recente com status="inactive"
previous = db.query(MLModel).filter_by(symbol=symbol, status="inactive")\
    .order_by(MLModel.trained_at.desc()).first()
previous.status = "active"

db.commit()
predictor.reload(symbol)
```

**Modelo carregado em memória — thread safety:**
```python
import threading

class ModelPredictor:
    def __init__(self):
        self._models: dict[str, Any] = {}
        self._lock = threading.RLock()  # reentrant lock para thread safety
    
    def predict(self, symbol, df):
        with self._lock:
            if symbol not in self._models:
                self.load_model(symbol)
            # ... rest of prediction
```

**250 candles suficientes?** `FeatureEngineer` precisa de 200+ candles para calcular EMA(200) sem NaN. Usar 250 candles garante features válidas para o último candle.

**Padrão de teste de integração:**
```python
import pytest
from httpx import AsyncClient
from unittest.mock import patch, MagicMock

@pytest.mark.asyncio
async def test_predict_returns_long(async_client: AsyncClient):
    mock_result = MagicMock(signal="LONG", confidence=0.80, model_version="rf_BTC_20260428")
    with patch("api.routes.ml.predictor.predict", return_value=mock_result):
        response = await async_client.post(
            "/api/v1/ml/predict",
            json={"symbol": "BTC/USDT"},
            headers={"Authorization": "Bearer test_token"}
        )
    assert response.status_code == 200
    assert response.json()["signal"] == "LONG"

@pytest.mark.asyncio
async def test_low_confidence_returns_neutral(async_client: AsyncClient):
    mock_result = MagicMock(signal="LONG", confidence=0.55, model_version="rf_BTC_20260428")
    with patch("api.routes.ml.predictor.predict", return_value=mock_result):
        response = await async_client.post(...)
    assert response.json()["signal"] == "NEUTRO"
```
