# Story 3.3: Verificação de Correlação entre Posições

## Status

Draft

## Story

**As a** engine de trading,
**I want** que o sistema verifique a correlação entre a nova posição candidata e as posições já abertas,
**so that** o portfólio não fique excessivamente exposto a um único fator de risco.

## Acceptance Criteria

1. Sistema calcula correlação de Pearson entre retornos dos últimos 20 candles do ativo candidato e de cada posição aberta
2. Sistema recusa abertura de nova posição se correlação com qualquer posição aberta for ≥ 0.7 (configurável)
3. Em modo paper trading, correlação é calculada mas não bloqueia — apenas registra em log e emite aviso
4. Log registra decisão de correlação para cada tentativa de abertura de posição
5. Testes unitários para função de cálculo de correlação e lógica de bloqueio

## Tasks / Subtasks

    - Buscar últimos N candles OHLCV do símbolo via Redis cache ou connector
    - Calcular retornos percentuais: `returns = [(c[i] - c[i-1]) / c[i-1] for i in range(1, len(closes))]`
    - Retornar lista de floats
  - [ ] Método `calculate_correlation(symbol_a, symbol_b, n_candles=20)`:
    - Buscar retornos dos dois símbolos
    - Calcular `numpy.corrcoef(returns_a, returns_b)[0][1]`
    - Retornar coeficiente de Pearson (-1 a +1)
  - [ ] Método `check(candidate_symbol, open_trades, threshold=0.7, is_paper=False)`:
    - Para cada trade aberto: calcular correlação entre `candidate_symbol` e `trade.symbol`
    - Se `abs(correlation) >= threshold`:
      - Logar: `log.warning("correlation_blocked", candidate=symbol, existing=trade.symbol, corr=corr)`
      - Se `is_paper=True`: não bloquear, apenas logar e retornar warning
      - Se `is_paper=False`: retornar `CorrelationCheckResult(blocked=True, reason=...)`
    - Retornar `CorrelationCheckResult(blocked=False)` se nenhuma correlação alta

  - [ ] Passar `is_paper=True` quando `bot_config.mode == "paper"`
- [ ] Escrever testes unitários (AC: 5)
  - [ ] `backend/tests/unit/test_correlation_checker.py`

  - [ ] Testar com zero posições abertas → não bloquear
  - [ ] Testar threshold configurável (0.5, 0.7, 0.9)

## Dev Notes

**Cálculo de correlação de Pearson com numpy:**
```python
import numpy as np

def calculate_correlation(self, returns_a: list[float], returns_b: list[float]) -> float:
    if len(returns_a) != len(returns_b) or len(returns_a) < 2:
        return 0.0  # não há dados suficientes — não bloquear por precaução
    corr_matrix = np.corrcoef(returns_a, returns_b)
    return float(corr_matrix[0][1])
```

**Uso de `abs(correlation)`:** O threshold é aplicado ao valor absoluto porque correlação -0.8 (inversa forte) também representa risco — ambos os ativos reagem fortemente ao mesmo evento, apenas em direções opostas. Com posições LONG em ambos (um sobe, outro cai), o resultado pode ser neutro — mas em condições de stress de mercado, correlações tendem a convergir para +1. Portanto, `abs >= threshold` é a abordagem conservadora correta.

**Candles para cálculo:** 20 candles de 1 hora = 20h de histórico. Suficiente para capturar correlação de curto prazo entre pares cripto.

**Cache Redis para retornos:**
```
Key: "returns:BTC/USDT:1h:20" → JSON list (TTL 60s)
Key: "returns:ETH/USDT:1h:20" → JSON list (TTL 60s)
```

**Limites práticos:**
- Se um símbolo não tiver 20 candles disponíveis: usar o que tiver (mínimo 5 candles para correlação válida)
- Se não houver dados: retornar `CorrelationCheckResult(blocked=False, warning="insufficient_data")`

**Threshold padrão:** 0.7 (configurável em `bot_config.max_corr_threshold`)

### Testing

**Framework:** pytest

**Localização:** `backend/tests/unit/test_correlation_checker.py`

**Cobertura obrigatória:** 90% em `backend/risk/` (conforme arquitetura seção 10.2)

**Exemplo de testes:**
```python
import numpy as np
from risk.correlation_checker import CorrelationChecker

def test_high_correlation_blocks_in_live():
    # BTC e ETH geralmente têm correlação alta
    btc_returns = [0.01, -0.02, 0.015, -0.005, 0.03, ...]  # 20 retornos
    eth_returns = [0.012, -0.018, 0.014, -0.004, 0.028, ...]  # muito similar
    
    checker = CorrelationChecker()
    corr = checker.calculate_correlation(btc_returns, eth_returns)
    assert abs(corr) >= 0.7  # correlação alta

    open_trades = [Trade(symbol="BTC/USDT", side="LONG")]
    result = checker.check("ETH/USDT", open_trades, threshold=0.7, is_paper=False)
    assert result.blocked is True

def test_high_correlation_allows_in_paper():
    # Em paper mode: não bloquear mesmo com correlação alta
    checker = CorrelationChecker()
    # ... (mesmos dados)
    result = checker.check("ETH/USDT", open_trades, threshold=0.7, is_paper=True)
    assert result.blocked is False
    assert result.warning is not None
```
