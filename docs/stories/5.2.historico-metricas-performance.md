# Story 5.2: Histórico de Operações e Métricas de Performance

## Status

Draft

## Story

**As a** owner do autoxtrade,
**I want** visualizar o histórico completo de operações e métricas de performance consolidadas,
**so that** eu possa avaliar a performance do bot ao longo do tempo e exportar dados para análise.

## Acceptance Criteria

1. Tabela paginada de operações encerradas (50 por página): data/hora, símbolo, lado, preço entrada, preço saída, P&L em R$ e %, duração
2. Filtros funcionais: período (hoje, 7d, 30d, personalizado), mercado (CRIPTO/B3/FOREX), resultado (lucro/prejuízo/todos)
3. Painel de métricas de performance: Win Rate, Profit Factor, Sharpe Ratio, P&L total, Max Drawdown histórico, P&L médio por operação
4. Gráfico de curva de equity interativo (Recharts) com zoom via mouse e marcadores de trades
5. Botão de exportação de dados em CSV (nome do arquivo: `autoxtrade-trades-{data}.csv`)
6. Todos os dados buscados via API REST com React Query (sem WebSocket — dados históricos não mudam em tempo real)

## Dev Notes

**Cálculo de métricas no backend:**
```python
# Profit Factor
pf = sum(t.pnl for t in trades if t.pnl > 0) / abs(sum(t.pnl for t in trades if t.pnl < 0))

# Win Rate
wr = len([t for t in trades if t.pnl > 0]) / len(trades) * 100

# Sharpe Ratio (simplificado — retorno diário)
returns = [day.pnl for day in daily_pnl]
sharpe = np.mean(returns) / np.std(returns) * np.sqrt(252) if np.std(returns) > 0 else 0
```

**React Query com paginação e filtros:**
```typescript
export function useTradeHistory(filters: TradeFilters, page: number) {
  return useQuery({
    queryKey: ["trades", "history", filters, page],
    queryFn: () => api.get("/api/v1/trades/history", { params: { ...filters, page } }).then(r => r.data),
    staleTime: 60_000,  // histórico não muda frequentemente
    keepPreviousData: true,  // evitar flash ao trocar página
  })
}
```

**Exportação CSV sem dependência extra (alternativa sem file-saver):**
```typescript
function downloadCsv(content: string, filename: string) {
  const url = URL.createObjectURL(new Blob([content], { type: "text/csv" }))
  const link = document.createElement("a")
  link.href = url
  link.download = filename
  link.click()
  URL.revokeObjectURL(url)
}
```
