# Story 7.1: Connector MetaTrader 5 Python API

## Status

Draft

## Story

**As a** engine de trading,
**I want** um connector para MetaTrader 5 que suporte B3 (ações brasileiras) e Forex,
**so that** o bot possa operar nesses mercados usando a mesma arquitetura do connector Binance.

## Acceptance Criteria

1. Classe `MT5Connector` implementa a mesma interface `BaseConnector` do connector Binance
2. Verificação automática de horário de mercado B3 (09h00–17h55 BRT) antes de qualquer operação
3. Métodos implementados: `get_price(symbol)`, `open_position(symbol, side, quantity)`, `close_position(trade_id)`, `get_open_positions()`
4. Stop-loss enviado como ordem separada (`ORDER_TYPE_SELL_STOP` / `ORDER_TYPE_BUY_STOP`) após abertura de posição
5. Tratamento de erros MT5: reconexão automática com backoff exponencial (3 tentativas)
6. Testes unitários com mock da biblioteca `MetaTrader5`

## Dev Notes

**Por que Windows/Wine é necessário:**
A biblioteca `MetaTrader5` Python é uma extensão C++ que comunica com o processo `terminal64.exe` do MT5 via COM/DDE. Só funciona em Windows nativo ou via Wine com configuração específica.

**Configurações de ambiente para MT5:**
```env
# .env
MT5_PATH=C:/Program Files/MetaTrader 5/terminal64.exe
MT5_LOGIN=123456
MT5_PASSWORD=sua_senha
MT5_SERVER=XPInvestimentos-Demo  # ou XPInvestimentos-Real
```

**Tipos de ordem MT5:**
```python
import MetaTrader5 as mt5

# Abrir posição comprada
request = {
    "action": mt5.TRADE_ACTION_DEAL,
    "symbol": "PETR4",           # B3: PETR4, VALE3, etc.
    "volume": 100.0,              # lotes (1 lote = 1 ação para B3)
    "type": mt5.ORDER_TYPE_BUY,
    "price": mt5.symbol_info_tick("PETR4").ask,
    "deviation": 20,              # slippage máximo em pontos
    "magic": 12345,               # ID do bot para identificar ordens
    "comment": "autoxtrade",
    "type_time": mt5.ORDER_TIME_GTC,
    "type_filling": mt5.ORDER_FILLING_IOC,
}

# Stop-loss como ordem separada (AC4)
stop_request = {
    "action": mt5.TRADE_ACTION_PENDING,
    "symbol": "PETR4",
    "volume": 100.0,
    "type": mt5.ORDER_TYPE_SELL_STOP,  # para fechar long
    "price": stop_loss_price,
    "magic": 12345,
}
```

**B3 — símbolos e convenções:**
- Ações: `PETR4`, `VALE3`, `ITUB4` (sem sufixo de exchange no MT5)
- Mini contratos futuros: `WINM24` (Mini Índice), `WDOK24` (Mini Dólar)
- Volume mínimo: 1 ação (à vista) ou 1 contrato (mini futuro)

**Forex — símbolos no MT5:**
- `EURUSD`, `USDBRL`, `GBPUSD` (convenção internacional)
- Volume em lotes: 0.01 lote = 1000 unidades (micro lot)
