# Story 3.1: Position Sizing Dinâmico

## Status

Draft

## Story

**As a** engine de trading,
**I want** calcular automaticamente o tamanho de cada posição com base no capital disponível e no risco percentual configurado,
**so that** nenhuma operação individual coloque mais do que o percentual definido do capital em risco.

## Acceptance Criteria

1. Fórmula implementada: `quantidade = (capital × risco_pct) / distância_stop_loss`
2. Parâmetro `risk_per_trade_pct` configurável via dashboard e API (padrão: 1%)
3. Sistema busca capital atual disponível antes de cada operação
4. Sistema recusa abertura de posição se o tamanho calculado exceder 10% do capital total (proteção extra)
5. Tamanho calculado é arredondado para o step size mínimo do par na exchange (ex: 0.001 BTC)
6. Endpoint `GET /api/v1/risk/sizing?symbol=BTC/USDT&stop_pct=1.5` retorna tamanho sugerido para simulação
7. Testes unitários com 100% de cobertura para função de cálculo de position size

## Dev Notes

**Fórmula de position sizing (risco fixo por trade):**
```python
def calculate(self, capital: Decimal, risk_pct: Decimal, entry_price: Decimal,
              stop_loss_price: Decimal, step_size: Decimal) -> PositionSizeResult:
    """
    Exemplo: capital=10000, risk_pct=1%, entry=287450, stop=282900, step=0.001
    stop_distance = abs(287450 - 282900) / 287450 = 1.583%
    risk_amount = 10000 * 0.01 = 100
    quantity_raw = 100 / (287450 * 0.01583) = 0.002197
    quantity = floor(0.002197 / 0.001) * 0.001 = 0.002 BTC
    check: 0.002 * 287450 = 574.90 <= 10000 * 0.10 = 1000 ✅
    """
    stop_distance = abs(entry_price - stop_loss_price) / entry_price
    risk_amount = capital * (risk_pct / Decimal("100"))
    quantity_raw = risk_amount / (entry_price * stop_distance)
    quantity = (quantity_raw / step_size).to_integral_value(ROUND_DOWN) * step_size

    max_position_value = capital * Decimal("0.10")
    if quantity * entry_price > max_position_value:
        quantity = (max_position_value / entry_price / step_size).to_integral_value(ROUND_DOWN) * step_size

    return PositionSizeResult(quantity=quantity, risk_amount=risk_amount, ...)
```

**Step sizes da Binance (exemplos):**
- BTC/USDT: 0.00001 BTC (spot), 0.001 BTC (futuros)
- ETH/USDT: 0.0001 ETH

Buscar via `exchange.load_markets()["BTC/USDT"]["limits"]["amount"]["min"]`.

**Usar `Decimal` para todos os cálculos financeiros** — nunca `float` (risco de erros de arredondamento).

**Exemplo de teste com valores conhecidos:**
```python
from decimal import Decimal
from risk.position_sizer import PositionSizer

def test_position_size_calculation():
    sizer = PositionSizer()
    result = sizer.calculate(
        capital=Decimal("10000"),
        risk_pct=Decimal("1"),
        entry_price=Decimal("287450"),
        stop_loss_price=Decimal("282900"),
        step_size=Decimal("0.001")
    )
    assert result.quantity == Decimal("0.002")
    assert result.risk_amount == Decimal("100.00")

def test_position_size_exceeds_10pct_cap():
    # Com stop muito próximo, posição seria > 10% do capital
    sizer = PositionSizer()
    result = sizer.calculate(
        capital=Decimal("10000"),
        risk_pct=Decimal("1"),
        entry_price=Decimal("287450"),
        stop_loss_price=Decimal("287160"),  # stop muito próximo (0.1%)
        step_size=Decimal("0.001")
    )
    assert result.quantity * result.entry_price <= Decimal("1000")  # max 10%
```
