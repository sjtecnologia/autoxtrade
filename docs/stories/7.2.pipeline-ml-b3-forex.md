# Story 7.2: Adaptação do Pipeline ML para B3 e Forex

## Status

Draft

## Story

**As a** pipeline ML,
**I want** treinar modelos específicos para B3 e Forex com features adaptadas a esses mercados,
**so that** as predições sejam relevantes considerando as particularidades de cada mercado.

## Acceptance Criteria

1. Dados históricos B3 coletados via `mt5.copy_rates_from()` para os símbolos configurados
2. Features adicionais específicas para B3: sessão do dia (abertura/meio-dia/fechamento), dia da semana, dias até vencimento de contratos futuros
3. Modelo treinado por símbolo individualmente (sem modelo genérico multi-mercado)
4. Pipeline de treino compartilha `FeatureEngineer` base do Epic 4 com extensão de features B3/Forex
5. Mesmo critério de aprovação: Profit Factor ≥ 1.3 no walk-forward backtesting

## Dev Notes

**`copy_rates_from` do MT5:**
```python
import MetaTrader5 as mt5
from datetime import datetime

rates = mt5.copy_rates_from(
    "PETR4",
    mt5.TIMEFRAME_H1,
    datetime.now(),   # a partir de agora, indo para o passado
    50000             # número de barras
)

df = pd.DataFrame(rates)
df["timestamp"] = pd.to_datetime(df["time"], unit="s", utc=True)
df = df.rename(columns={"tick_volume": "volume"})
df = df[["timestamp", "open", "high", "low", "close", "volume"]]
```

**Feature `days_to_expiry` para futuros:**
```python
# Minicontrato de Índice WINM24: vence 3ª sexta-feira de junho/2024
FUTURES_EXPIRY = {
    "WINM24": date(2024, 6, 19),  # 3ª sexta-feira de jun/24
    "WDOK24": date(2024, 11, 20), # 3ª quarta-feira de nov/24
}

def days_to_expiry(symbol: str, current_date: date) -> int:
    expiry = FUTURES_EXPIRY.get(symbol[:6])  # primeiros 6 chars
    if not expiry:
        return -1  # não é futuro
    return max(0, (expiry - current_date).days)
```

**One-hot encoding de sessão B3:**
```python
def encode_session(hour: int) -> dict:
    return {
        "session_abertura": 1 if 9 <= hour < 11 else 0,
        "session_meio_dia": 1 if 11 <= hour < 16 else 0,
        "session_fechamento": 1 if 16 <= hour < 18 else 0,
    }
```

**Por que modelos por símbolo (não genérico):**
- PETR4 e VALE3 têm dinâmicas completamente diferentes (petróleo vs minério)
- EURUSD e USDBRL respondem a diferentes fatores macroeconômicos
- Modelo genérico multi-ativo tende a ser medíocre em todos em vez de bom em algum
