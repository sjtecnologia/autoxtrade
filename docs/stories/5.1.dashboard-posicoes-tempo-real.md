# Story 5.1: Dashboard Principal com Posições em Tempo Real

## Status

Draft

## Story

**As a** owner do autoxtrade,
**I want** visualizar todas as posições abertas e métricas do dia em tempo real no dashboard,
**so that** eu possa monitorar o bot sem precisar consultar a exchange diretamente.

## Acceptance Criteria

1. Tabela de posições abertas atualizada em tempo real via WebSocket: símbolo, lado (LONG/SHORT), preço de entrada, preço atual, P&L em R$ e %, tempo aberto, stop-loss, take-profit
2. Métricas do dia exibidas: P&L total do dia, número de trades, Win Rate
3. Status badges do bot por mercado (CRIPTO, B3, FOREX): ATIVO/PAUSADO/DESCONECTADO com cor correspondente (verde/amarelo/cinza)
4. Sparkline de equity das últimas 24h no header
5. Barra de drawdown mostrando drawdown atual (30d) com cores: verde (<10%), amarelo (10-15%), vermelho (>15%)
6. Banners de alerta exibidos quando drawdown ≥ 10% (amarelo) ou ≥ 15% (vermelho com "TRADING PAUSADO")
7. Interface responsiva e em dark mode

**Zustand store:**
```typescript
// frontend/store/botStore.ts
import { create } from "zustand"

interface BotStore {
  positions: Position[]
  botStatus: Record<string, "ATIVO" | "PAUSADO" | "DESCONECTADO">
  setPositions: (positions: Position[]) => void
  setBotStatus: (market: string, status: string) => void
}

export const useBotStore = create<BotStore>((set) => ({
  positions: [],
  botStatus: {},
  setPositions: (positions) => set({ positions }),
  setBotStatus: (market, status) =>
    set((state) => ({ botStatus: { ...state.botStatus, [market]: status } })),
}))
```

**React Query para dados REST:**
```typescript
import { useQuery } from "@tanstack/react-query"
import { api } from "@/lib/api"

export function useDrawdown() {
  return useQuery({
    queryKey: ["drawdown"],
    queryFn: () => api.get("/api/v1/risk/drawdown").then(r => r.data),
    refetchInterval: 60_000,  // 60 segundos
    staleTime: 30_000,
  })
}
```
