# Story 1.1: Setup do Repositório e Estrutura do Projeto

## Status

Draft

## Story

**As a** owner do autoxtrade,
**I want** o repositório Git criado com a estrutura de pastas definida, .gitignore, e documentação inicial,
**so that** a base do projeto esteja organizada e pronta para desenvolvimento.

## Acceptance Criteria

1. Repositório Git inicializado com branches `main` e `develop`
2. Estrutura de pastas criada: `backend/`, `frontend/`, `docs/`, `scripts/`
3. `.gitignore` configurado para Python, Node.js e arquivos de ambiente (`.env`, `*.pem`, `*.key`)
4. `README.md` com visão geral do projeto e instruções básicas de setup
5. `requirements.txt` (Python) e `package.json` (Next.js) com dependências iniciais definidas

## Dev Notes

**Estrutura de diretórios completa definida em:** `docs/fullstack-architecture.md` seção 5

**Estrutura-chave do backend:**
```
backend/
├── main.py                     # entrypoint FastAPI
├── config.py                   # Settings (pydantic-settings, lê .env)
├── database.py                 # engine SQLAlchemy, session factory
├── api/
│   ├── router.py               # inclui todos os routers
│   ├── auth.py                 # bearer token middleware
│   ├── websocket.py            # WS endpoint + broadcast
│   └── routes/                 # health.py, positions.py, trades.py, etc.
├── trading/connectors/         # base.py, binance.py, mt5.py
├── risk/                       # manager.py, position_sizer.py, drawdown_monitor.py, correlation_checker.py
├── ml/                         # pipeline.py, trainer.py, validator.py, predictor.py
├── notifications/              # telegram.py, templates.py
└── tasks/                      # celery_app.py, ml_tasks.py, report_tasks.py
```

**Variáveis de ambiente (.env.example) — chaves principais:**
```bash
# API Authentication
SECRET_TOKEN=<gerado com secrets.token_hex(32)>

# Binance
BINANCE_API_KEY=
BINANCE_API_SECRET=
BINANCE_PAPER_MODE=true

# Telegram
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=

# Database
DATABASE_URL=postgresql+asyncpg://autoxtrade:password@postgres:5432/autoxtrade

# Redis
REDIS_URL=redis://redis:6379/0
```

**Branches:**
- `main` = produção (deploy automático via `scripts/deploy.sh`)
- `develop` = desenvolvimento ativo
- Feature branches: `feature/story-X.Y-descricao`

**Segurança:** `.env` NUNCA no git. `.gitignore` deve incluir `.env` e `.env.*` com exceção de `.env.example`.

### Testing

- Esta story não gera código testável via pytest/jest — é setup de estrutura
- Verificação manual: `git status` em pastas criadas, `git log --oneline` para confirmar commits
- Próxima story (1.2) vai criar os Dockerfiles e validar o build
