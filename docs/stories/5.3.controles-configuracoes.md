# Story 5.3: Controles do Bot e Página de Configurações

## Status

Draft

## Story

**As a** owner do autoxtrade,
**I want** pausar/retomar o bot e ajustar parâmetros de risco diretamente no dashboard,
**so that** eu possa gerenciar o bot sem precisar acessar o servidor via SSH.

## Acceptance Criteria

1. Botões de Pausar e Retomar o bot por mercado, com modal de confirmação antes de executar
2. Formulário de configuração de risco: `risk_per_trade_pct`, `max_open_positions`, `max_drawdown_pct`, `drawdown_alert_pct`, `max_corr_threshold`
3. Validação no cliente (campos obrigatórios, valores numéricos dentro de limites razoáveis) E no servidor
4. Toda alteração de configuração registrada em `config_audit_log` com timestamp e valor anterior
5. Notificação Telegram enviada quando bot é pausado ou retomado manualmente
6. Exibir histórico das últimas 10 alterações de configuração (quem, quando, o que mudou)

## Dev Notes

**Pydantic validation no servidor:**
```python
class RiskConfigUpdate(BaseModel):
    risk_per_trade_pct: Optional[float] = Field(None, ge=0.005, le=0.05)
    max_open_positions: Optional[int] = Field(None, ge=1, le=10)
    max_drawdown_pct: Optional[float] = Field(None, ge=5, le=30)
    drawdown_alert_pct: Optional[float] = Field(None, ge=3, le=25)
    max_corr_threshold: Optional[float] = Field(None, ge=0.3, le=1.0)
```

**config_audit_log — formato:**
```json
{
  "market": "CRIPTO",
  "field": "risk_per_trade_pct",
  "old_value": "0.01",
  "new_value": "0.02",
  "changed_at": "2026-04-28T12:00:00Z"
}
```
Nota: `old_value` e `new_value` armazenados como strings JSON para suportar qualquer tipo de valor.

**React Hook Form + Zod:**
```typescript
import { useForm } from "react-hook-form"
import { zodResolver } from "@hookform/resolvers/zod"

const form = useForm<RiskConfig>({
  resolver: zodResolver(schema),
  defaultValues: currentConfig,  // pré-preencher com valores atuais
})
```

**Otimismo UI para Pausar/Retomar:**
- Não aplicar UI otimista — aguardar confirmação do servidor antes de atualizar estado
- Razão: ação de pausa tem impacto real no trading; falsa sensação de sucesso é perigosa
