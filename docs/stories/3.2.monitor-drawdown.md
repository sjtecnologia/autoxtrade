# Story 3.2: Monitor de Drawdown e Pausas Automáticas

## Status

Draft

## Story

**As a** owner do autoxtrade,
**I want** que o sistema monitore continuamente o drawdown e pause automaticamente as operações ao atingir limites configurados,
**so that** o capital seja protegido em períodos adversos de mercado.

## Acceptance Criteria

1. Sistema calcula drawdown atual em tempo real: `(pico_capital - capital_atual) / pico_capital × 100`
2. Drawdown calculado em janelas de 1 dia e 30 dias
3. Ao atingir 10% de drawdown (30 dias): notificação Telegram de alerta; dashboard exibe banner de aviso amarelo
4. Ao atingir 15% de drawdown (30 dias): todas as novas ordens são bloqueadas automaticamente; notificação Telegram de emergência; dashboard exibe banner vermelho "TRADING PAUSADO"
5. Owner pode retomar trading manualmente via dashboard após reconhecer o alerta, mesmo com drawdown > 15%
6. Endpoint `GET /api/v1/risk/drawdown` retorna drawdown atual (1d e 30d) e status (ok/warning/paused)
7. Testes unitários para lógica de cálculo de drawdown e trigger de pausas

## Dev Notes

**Cálculo de drawdown:**
```python
from decimal import Decimal

def calculate_drawdown(snapshots: list[EquitySnapshot]) -> DrawdownResult:
    """
    snapshots: lista ordenada por snapshot_at ASC, últimos 30 dias
    """
    equities = [s.equity for s in snapshots]
    if not equities:
        return DrawdownResult(dd_1d=Decimal("0"), dd_30d=Decimal("0"), ...)

    peak_30d = max(equities)
    current = equities[-1]
    dd_30d = (peak_30d - current) / peak_30d * Decimal("100") if peak_30d > 0 else Decimal("0")

    # Drawdown 1 dia
    yesterday_equity = equities[0] if len(equities) < 2 else equities[-24]  # ~24h atrás (snapshots de hora em hora)
    dd_1d = (yesterday_equity - current) / yesterday_equity * Decimal("100") if yesterday_equity > 0 else Decimal("0")

    return DrawdownResult(dd_1d=dd_1d, dd_30d=dd_30d, peak_capital=peak_30d, current_equity=current)
```

**Campo `drawdown_status` em `bot_config`:**
```
"OK"      → trading ativo, abaixo de 10%
"WARNING" → entre 10% e 15%, alerta enviado, trading continua
"PAUSED"  → acima de 15%, ordens bloqueadas automaticamente
```

**Fluxo de drawdown automático (da arquitetura seção 4.4):**
```
Celery Beat (5min) → DrawdownMonitor.check_and_enforce()
  → Calcula dd_30d
  → Se ≥ 10%: WARNING + Telegram alert
  → Se ≥ 15%: PAUSED + is_active=False + Telegram emergency
  → Publica DRAWDOWN_ALERT via Redis → WebSocket broadcast → frontend mostra banner
```

**Equity = saldo USDT livre + mark-to-market de posições abertas:**
```python
equity = usdt_balance + sum(
    (current_price - trade.entry_price) * trade.quantity * (1 if trade.side == "LONG" else -1)
    for trade in open_trades
)
```

```python
def test_drawdown_trigger_paused_at_15pct():
    snapshots = [
        EquitySnapshot(equity=Decimal("10000"), snapshot_at=...),  # pico
        EquitySnapshot(equity=Decimal("8800"), snapshot_at=...),   # -12%, WARNING
        EquitySnapshot(equity=Decimal("8490"), snapshot_at=...),   # -15.1%, PAUSED
    ]
    monitor = DrawdownMonitor()
    result = monitor.calculate_drawdown(snapshots)
    assert result.dd_30d >= Decimal("15")

def test_blocked_when_paused(bot_config_paused, risk_manager):
    # bot_config com drawdown_status="PAUSED"
    allowed = risk_manager.can_open_position(market="CRIPTO")
    assert allowed is False
```
