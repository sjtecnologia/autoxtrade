# Story 4.3: Treinamento do Modelo Random Forest e Backtesting Walk-Forward

## Status

Draft

## Story

**As a** sistema ML,
**I want** treinar e validar um modelo Random Forest usando walk-forward backtesting,
**so that** apenas modelos com performance mínima (Profit Factor ≥ 1.3) sejam aprovados para produção.

## Acceptance Criteria

1. Pipeline de treinamento usa `RandomForestClassifier` (scikit-learn) com `GridSearchCV` para otimização de hiperparâmetros
2. Backtesting walk-forward com 4 folds: 12 meses de treino + 3 meses de teste, janelas deslizantes
3. Métricas de validação calculadas por fold: Profit Factor, Win Rate, total de trades simulados
4. Modelo aprovado somente se Profit Factor médio dos folds ≥ 1.3
5. Modelo treinado salvo como arquivo na pasta `backend/ml/models/` com versão baseada em timestamp
6. Registro do modelo no banco de dados (tabela `ml_models`) com métricas, status e caminho do arquivo
7. Testes unitários para lógica de validação de métricas (mock dos dados)

## Dev Notes

**Walk-Forward — conceito crítico para séries temporais:**
```
Fold 1: Treino [Jan/22–Dez/22] → Teste [Jan/23–Mar/23]
Fold 2: Treino [Apr/22–Mar/23] → Teste [Apr/23–Jun/23]
Fold 3: Treino [Jul/22–Jun/23] → Teste [Jul/23–Set/23]
Fold 4: Treino [Out/22–Set/23] → Teste [Out/23–Dez/23]

NUNCA usar dados futuros para treino — sempre preservar ordem temporal!
```

**TimeSeriesSplit do scikit-learn:**
```python
from sklearn.model_selection import TimeSeriesSplit, GridSearchCV

tscv = TimeSeriesSplit(n_splits=3)
param_grid = {
    "n_estimators": [100, 200],
    "max_depth": [5, 10, None],
    "min_samples_split": [2, 5]
}
grid_search = GridSearchCV(
    RandomForestClassifier(random_state=42, class_weight="balanced"),
    param_grid,
    cv=tscv,
    scoring="f1_weighted",
    n_jobs=-1
)
```

**Cálculo de Profit Factor:**
```python
def calculate_profit_factor(trades: list[dict]) -> float:
    """
    trades: [{"pnl": +50.0}, {"pnl": -20.0}, ...]
    """
    gains = sum(t["pnl"] for t in trades if t["pnl"] > 0)
    losses = abs(sum(t["pnl"] for t in trades if t["pnl"] < 0))
    if losses == 0:
        return float("inf")  # só vencedores — aprovado
    return gains / losses
```

**Simulação de trades durante validação:**
```python
# Para cada sinal LONG no set de teste:
# Entrada: close do candle T
# Saída: close do candle T+5 (N forward candles)
# PnL = (exit_close - entry_close) / entry_close * 100
```

**`class_weight="balanced"`:** Essencial porque dataset desbalanceado (mais candles NEUTRO do que LONG/SHORT).

**Exemplo de testes:**
```python
from ml.validator import ModelValidator

def test_approval_at_threshold():
    validator = ModelValidator()
    metrics = type("M", (), {"profit_factor": 1.3})()
    assert validator.check_approval(metrics) is True

def test_rejection_below_threshold():
    validator = ModelValidator()
    metrics = type("M", (), {"profit_factor": 1.29})()
    assert validator.check_approval(metrics) is False

def test_profit_factor_calculation():
    validator = ModelValidator()
    trades = [
        {"pnl": 100.0}, {"pnl": -50.0}, {"pnl": 80.0}, {"pnl": -20.0}
    ]
    # gains=180, losses=70, PF = 180/70 = 2.57
    pf = validator.calculate_profit_factor(trades)
    assert abs(pf - 180/70) < 0.001
```
