# Story 0.1: Checklist de Pre-requisitos do Owner

## Status

Draft

## Story

**As a** owner do autoxtrade,
**I want** garantir que todos os pre-requisitos externos estão configurados e verificados,
**so that** o desenvolvimento possa iniciar no Epic 1 sem bloqueios de infraestrutura ou contas externas.

## Acceptance Criteria

1. VPS provisionado (Ubuntu 22.04 LTS, mínimo 4GB RAM, 40GB SSD) com IP fixo e acesso SSH por chave configurado (login por senha desabilitado)
2. Domínio ou subdomínio apontando para o IP do VPS configurado no DNS
3. Docker e Docker Compose instalados no VPS e funcionando (`docker --version` e `docker compose version` retornam sem erro)
4. Conta Binance ativa com KYC concluído; API Key criada com permissões **Read + Trade** (sem Withdrawal); IP Whitelist do VPS configurado na API Key
5. Bot Telegram criado via `@BotFather`; token e chat_id obtidos e testados (envio de mensagem de teste bem-sucedido)
6. Repositório GitHub privado criado; chave SSH do VPS adicionada ao GitHub como Deploy Key
7. Arquivo `.env` base criado no VPS a partir do `.env.example` com as credenciais reais preenchidas (Binance keys, Telegram token/chat_id, SECRET_TOKEN gerado)
8. **MT5 (pode ser adiado para Epic 7):** Conta aberta em XP Investimentos ou Modal Mais; MetaTrader 5 instalado e autenticado; login/senha/servidor anotados

## Tasks / Subtasks

- [ ] Provisionar VPS (AC: 1)
  - [ ] Criar conta em provedor (Hetzner, Vultr SP, DigitalOcean SP ou Contabo)
  - [ ] Selecionar plano ≥ 4GB RAM, 40GB SSD, Ubuntu 22.04 LTS
  - [ ] Configurar chave SSH: `ssh-keygen -t ed25519` localmente; adicionar chave pública ao VPS
  - [ ] Desabilitar login por senha: editar `/etc/ssh/sshd_config` → `PasswordAuthentication no`
  - [ ] Verificar IP fixo alocado ao VPS
- [ ] Configurar DNS (AC: 2)
  - [ ] Registrar domínio ou usar subdomínio existente
  - [ ] Criar registro A apontando para o IP do VPS
  - [ ] Aguardar propagação DNS (pode levar até 24h)
- [ ] Instalar Docker no VPS (AC: 3)
  - [ ] Executar: `curl -fsSL https://get.docker.com | sh`
  - [ ] Adicionar usuário ao grupo docker: `usermod -aG docker $USER`
  - [ ] Instalar Docker Compose plugin: já incluso no Docker Engine v24+
  - [ ] Verificar: `docker compose version`
- [ ] Configurar Binance API Key (AC: 4)
  - [ ] Acessar Binance > Perfil > API Management > Create API
  - [ ] Habilitar: ✅ Enable Reading + ✅ Enable Spot & Margin Trading
  - [ ] Desabilitar: ❌ Enable Withdrawals ❌ Enable Transfers
  - [ ] Adicionar IP do VPS na IP Whitelist
  - [ ] Copiar API Key e Secret para local seguro
- [ ] Criar Bot Telegram (AC: 5)
  - [ ] Abrir Telegram → @BotFather → `/newbot`
  - [ ] Seguir instruções, copiar token gerado
  - [ ] Obter chat_id: enviar mensagem ao bot; acessar `https://api.telegram.org/bot<TOKEN>/getUpdates`
  - [ ] Testar envio: `curl -s -X POST https://api.telegram.org/bot<TOKEN>/sendMessage -d chat_id=<ID> -d text="autoxtrade test"`
- [ ] Configurar repositório GitHub (AC: 6)
  - [ ] Criar repositório privado `autoxtrade` no GitHub
  - [ ] Gerar chave SSH no VPS: `ssh-keygen -t ed25519 -C "autoxtrade-vps"`
  - [ ] Adicionar chave pública em GitHub > Settings > Deploy Keys (read/write)
  - [ ] Testar: `ssh -T git@github.com`
- [ ] Criar arquivo .env inicial no VPS (AC: 7)
  - [ ] Gerar SECRET_TOKEN: `python3 -c "import secrets; print(secrets.token_hex(32))"`
  - [ ] Copiar `.env.example` para `.env`
  - [ ] Preencher: `BINANCE_API_KEY`, `BINANCE_API_SECRET`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `SECRET_TOKEN`
  - [ ] Verificar: `.env` não está no git (confirmar `.gitignore` cobre `*.env` e `.env`)
- [ ] Configurar MT5 (AC: 8 — pode adiar para Epic 7)
  - [ ] Criar conta em XP Investimentos ou Modal Mais (gratuito)
  - [ ] Baixar e instalar MetaTrader 5 da corretora
  - [ ] Autenticar com credenciais da conta
  - [ ] Anotar: login (número), senha, nome do servidor (ex: `XPInvestimentos-Real`)

## Dev Notes

**Infraestrutura alvo:** VPS Ubuntu 22.04 LTS (fase 1, só cripto). Para fase 1b (MT5/B3), será necessário migrar para Windows Server ou configurar Wine — isso é tratado no Epic 7.

**Provedores de VPS recomendados:**
- Hetzner Cloud (Europa, melhor custo-benefício): CPX11 = €4.15/mês (2 vCPU, 2GB RAM) — subir para CX22 (4GB) = ~€5.77/mês
- Vultr São Paulo: $12/mês (2 vCPU, 4GB RAM) — menor latência para B3
- DigitalOcean São Paulo: $24/mês (2 vCPU, 4GB RAM)

**Geração de SECRET_TOKEN:**
```bash
python3 -c "import secrets; print(secrets.token_hex(32))"
```
Guarde esse token com segurança — é a única autenticação do dashboard.

**Binance API key — permissões corretas:**
```
✅ Enable Reading
✅ Enable Spot & Margin Trading
❌ Enable Withdrawals (NUNCA habilitar)
❌ Enable Futures (não necessário no MVP)
```
IP Whitelist é obrigatório pela política de segurança do projeto (NFR5, NFR6).

**Estrutura de diretório para deploy no VPS:**
```
/opt/autoxtrade/
├── .env          (credenciais reais — chmod 600)
├── docker-compose.yml
└── (demais arquivos do repositório)
```

**Referências:**
- `.env.example` → `docs/fullstack-architecture.md` seção 6.4
- Script setup VPS → `scripts/setup_vps.sh` (criado na Story 1.1)
- Diagrama de componentes → `docs/fullstack-architecture.md` seção 1.2
